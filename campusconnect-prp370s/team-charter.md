# Agile Team Charter — CampusConnect Marketplace

**Status:** Draft based on the project documentation. Confirm all team agreements against the actual Trello charter and meeting records before treating them as approved.

## 1. Shared purpose

Build a university-exclusive, browser-based peer-to-peer marketplace intended to help students find and exchange academic items in a safer and more structured way than informal social-media trading.

The documented product concept includes verified university-email access, profiles, listings, search/filtering, buyer–seller messaging, reviews/ratings, administrator moderation and approved campus/library collection points.

## 5. Scope boundaries documented for CampusConnect

The supplied Project 3 documentation describes a web application designed for desktop and mobile browsers, not a native Android/iOS application. It excludes integrated payment gateways from the initial scope. Its business rules cover unique university emails, authenticated access, listing ownership, non-negative prices, search/filtering, in-app messaging, ratings within 1–5, moderation, approved collection points and protection of authentication information.

The implementation-readiness checklist says the ERD and attributes must be reconciled with the actual database and that UI concepts should be supplemented with screenshots of the working system. These remain verification tasks unless implementation evidence is available.
